How the evaluation set is built: the model is scored once per held-out terminal per eligible day. One terminal observed on one scored day = one prediction observation.

1,000held-out terminals
× 24scored days per terminal
= 24,000prediction observations

Why 24 days? The simulation spans 30 days, but days 0–5 are removed before modelling so trailing-history features have prior context. Moving the threshold changes only the action rule applied to these same 24,000 observations.
